# 游戏列表自动续载（2026-09-20）

已发布版本：`45788ea6-3544-4d8d-8993-2361a0adba0d`。

原先全部、热门、新游戏、分类及搜索结果每页显示 24 款，需要不断点击下一页。现统一改为首批服务端渲染 60 款，滚动接近底部时自动请求下一批 60 款并追加到原列表。保留“Load more games”按钮用于手动加载或浏览器不支持自动观察时使用，网络错误显示重试且保留已有卡片。没有更多内容时显示结束提示。

新增只读 `/api/games`，限定批量大小及页码范围，保留搜索、分类和排序条件；不接受前台传入草稿访问开关或任意查询大小。排序增加游戏 ID 作为同分同名记录的稳定顺序，客户端按 ID 去重、阻止并发重复请求，并在离开列表时取消请求。旧 `?page=` 链接及无脚本的下一批链接仍可访问。

浏览器内缓存最近 3 个列表，保留 5 分钟，便于进入游戏后返回已经加载的位置；搜索、分类、排序、起始页分别缓存，互不混入。缓存不写入数据库，也不存储用户账号或游戏内信息。

验证结果：

- lint、类型检查、55 项单元/集成测试、生产构建通过。
- 本地与线上初始 60 张卡，向底部滚动后均自动追加到 120 张，ID/链接无重复。
- 本地从第 81 个卡片进入游戏，再返回列表，仍有 120 张卡，并恢复原有滚动位置。
- 搜索 2048 返回 21 款，Cooking 分类返回 11 款，切换后没有混入之前的列表；末尾不再显示加载按钮。
- 验证时生产 D1 为 775 款独立游戏、801 条来源（与首次部署的 801 款独立游戏数量不同，本次未改动目录）。第 13 批返回最后 55 款，`nextPage=null`；非法页码返回 400。
- 顺序读取线上全部 13 批，共 775 个不同游戏 ID，没有漏项或重复。先前并发探测曾遇到一次 HTTP 503，随后该页及完整顺序读取均返回正常，完整读取无需重试。
- 线上原始 HTML 中含 60 张游戏卡；首批不依赖浏览器发请求后才能展示。
- 390 像素手机宽度下检查两列卡片、导航和横向溢出，布局正常。

HTTP 验证记录位于忽略版本控制的 `.wrangler/deployment/collection-smoke.json`。没有修改游戏数据、后台分页或供应商同步设置。
